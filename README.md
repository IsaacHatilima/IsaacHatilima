## Engineering Approach

I believe good software should be:

- **Understandable** — clear architecture and readable code
- **Maintainable** — sensible abstractions without unnecessary complexity
- **Reliable** — tested, monitored and designed for failure
- **Secure** — authentication, authorization and data protection considered early
- **Observable** — production behaviour should be measurable and diagnosable
- **Pragmatic** — technical decisions should support real product and business needs

AI-assisted development can improve engineering speed, but generated output still requires human understanding, review, testing and accountability.
